# 🌐 Як зробити сайт доступним 24/7 в інтернеті

Щоб сайт працював у будь-який час доби для всіх ваших друзів (навіть коли ваш комп'ютер вимкнено), його потрібно розмістити на безкоштовному хмарному хостингу.

Оскільки проєкт написаний на чистому Python без важких залежностей, його можна запустити абсолютно **безкоштовно** за 3–5 хвилин.

---

## 🥇 Варіант 1: Render.com (Найкращий та найпростіший, 100% безкоштовно)

Render автоматично надає безкоштовний домен з HTTPS (наприклад: `https://our-meetups.onrender.com`).

### Покрокова інструкція:
1. **Завантажте проєкт на GitHub**:
   - Створіть новий безкоштовний репозиторій на [GitHub.com](https://github.com) (наприклад, `friends-meetup`).
   - Завантажте туди всі файли з цієї папки.
2. **Зареєструйтесь на [Render.com](https://render.com)** (можна увійти через GitHub в 1 клік).
3. Натисніть кнопку **New +** вгорі праворуч і оберіть **Web Service**.
4. Оберіть ваш репозиторій GitHub (`friends-meetup`).
5. Вкажіть базові налаштування:
   - **Name**: назва вашого сайту (наприклад, `friends-coffee-meetup`)
   - **Language**: `Python 3`
   - **Build Command**: залиште порожнім або `pip install -r requirements.txt`
   - **Start Command**: `python server.py`
   - **Plan**: оберіть **Free ($0/month)**
6. Натисніть кнопку **Create Web Service**.

> 🎉 **Готово!** Через 1-2 хвилини Render надасть вам посилання виду `https://friends-coffee-meetup.onrender.com`. Надішліть його друзям — сайт працюватиме 24/7!

## 🥈 Варіант 2: Railway.app (Миттєвий деплой без налаштувань)

1. Зареєструйтесь на [Railway.app](https://railway.app) через GitHub.
2. Натисніть **+ New Project** -> **Deploy from GitHub repo**.
3. Оберіть ваш репозиторій. Railway автоматично розпізнає `Dockerfile` або `Procfile` і запустить сайт.
4. У вкладці **Settings** натисніть **Generate Domain**, щоб отримати публічне посилання.

---

## 🥉 Варіант 3: PythonAnywhere (Спеціалізований безкоштовний Python-хостинг)

1. Зареєструйтесь на [PythonAnywhere.com](https://www.pythonanywhere.com) (безкоштовний акаунт Beginner).
2. У вкладці **Files** завантажте файли сайту.
3. У вкладці **Web** створіть новий застосунок та запустіть `server.py`.
4. Ви отримаєте постійне посилання `https://ваш_логін.pythonanywhere.com`.

## 💡 Тимчасовий доступ прямо зараз без завантаження на хостинг (ngrok / localtunnel)

Якщо ви хочете скинути посилання друзям прямо зараз на пару годин, поки ваш ПК увімкнений:
1. Завантажте утиліту [ngrok](https://ngrok.com) або використайте `localtunnel`:
   ```bash
   npx localtunnel --port 8000
   ```
2. Ви отримаєте публічне посилання (наприклад: `https://cool-friends.loca.lt`), яке одразу працюватиме ззовні.
