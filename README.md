# ☕ Зустрічі з друзями (Friends Meetup Scheduler)

Сучасний вебзастосунок для зручного планування зустрічей з друзями згідно з усіма вимогами ТЗ.

## 🌟 Основний функціонал

1. **Календар 2 найближчих місяців**:
   - Одночасне відображення поточного та наступного місяців поруч.
   - Зручна навігація між місяцями та повернення до сьогоднішнього дня.
   - Візуальні бейджі запланованих зустрічей прямо на днях календаря.
   - Вибір дати в один клік для планування або перегляду деталей.

2. **Гнучкий вибір формату зустрічі**:
   - 🚶 **Прогулянка** (на свіжому повітрі)
   - ☕ **Кафе**
   - ✨ **Щось інше** (настільні ігри, пікнік, кіно з власним описом)

3. **Вибір локації для Кафе**:
   - 🌟 **Star Cup**
   - 🌿 **Light Mood**
   - ⛺ **Жовтий навєсік**

4. **Вибір напоїв**:
   - ☕ **Кава**
   - 🍵 **Чай**
   - 🥤 **Щось інше**
   - Доступно як організатору під час створення, так і кожному другові під час приєднання до зустрічі.

5. **Примітки та коментарі**:
   - Будь-хто з друзів може залишити коментар/примітку (наприклад: *«Запізнюсь на 10 хвилин»*, *«Візьму з собою фотоапарат»*).
   - Коментарі відображаються у хронологічному порядку з аватаркою та часом відправки.

6. **Публічні та приватні зустрічі**:
   - 🌐 **Публічна**: доступна усім друзям у календарі з кнопкою «+ Приєднатися» (RSVP).
   - 🔒 **Приватна**: для окремих зустрічей або за прямим посиланням.

7. **Експорт у календарі («Додати в календар»)**:
   - 📅 **Google Calendar**: миттєве відкриття та додавання події онлайн.
   - 🍏 **Apple Calendar / Outlook (.ics)**: завантаження стандартного файлу календаря.
   - 📝 **Notion**: швидкий перехід до Notion Calendar та копіювання готової форматованої картки зустрічі.

8. **Динамічні анімації та UI**:
   - Святковий феєрверк конфеті на Canvas при створенні та приєднанні.
   - Звукові сигнали через Web Audio API.
   - Ефект скла (glassmorphism), плавні пружинні модальні вікна та ефект хвиль (ripple) на кнопках.

9. **Вибір власної аватарки**:
   - Колекція трендових емодзі-аватарів або завантаження власного фото.
   - Відображення аватарки біля створених зустрічей, голосів за напої та приміток.

10. **Пуш-нагадування (Web Push)**:
    - Нагадування у браузері за 15 хвилин, 1 годину або 1 день до зустрічі.
    - Кнопка швидкої перевірки «🔔 Перевірити пуш зараз».

---

## 🚀 Як запустити проєкт

### Варіант 1 (Найпростіший на Windows)
Двічі клікніть на файл `start.bat`. Він автоматично відкриє браузер на `http://localhost:8000` та запустить локальний сервер.

### Варіант 2 (Через термінал)
```bash
python server.py
```
Після цього відкрийте у вашому браузері: [http://localhost:8000](http://localhost:8000)

## 🛠 Технічний стек
- **Бекенд**: Python 3 (використовує тільки стандартну бібліотеку `http.server`, `sqlite3`, `json` — не потребує `pip install`).
- **База даних**: SQLite (`meetups.db`).
- **Фронтенд**: HTML5, Tailwind CSS, JavaScript ES6+, Web Notifications API, Web Audio API, HTML5 Canvas.
